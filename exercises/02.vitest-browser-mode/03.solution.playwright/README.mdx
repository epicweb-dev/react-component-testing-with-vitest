# Playwright

<EpicVideo url="https://www.epicweb.dev/workshops/react-component-testing-with-vitest/vitest-browser-mode/playwright/solution" />

Let's start by installing `playwright` and the Playwright provider for Vitest:

```sh nonumber
npm i -D playwright @vitest/browser-playwright
```

Playwright needs browser executables to be present on your machine to run. In this workshop, I am using Chromium as my browser of choice, so I can install just that particular browser by running the following command:

```sh nonumber
npx playwright install --with-deps chromium
```

> 🦉 You can provide the Playwright CLI with a specific browser you want to be installed. This reduces its footprint in the system by fetching only the browsers you need.

The next step is to tell Vitest to use Playwright as the browser provider for component tests. In `vite.config.ts`, import the `playwright` provider from `@vitest/browser-playwright` and set it as the value of the `test.browser.provider` option:

```ts filename=vite.config.ts remove=3 add=4,13
/// <reference types="vitest/config" />
import { defineConfig } from 'vite'
import { preview } from '@vitest/browser-preview'
import { playwright } from '@vitest/browser-playwright'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
	plugins: [react(), tailwindcss()],
	test: {
		globals: true,
		browser: {
			enabled: true,
			provider: playwright(),
			instances: [
				{
					browser: 'chromium',
				},
			],
		},
	},
})
```

> 🦉 Browser providers are _functions_. This is where you pass any provider-specific options, like `launchOptions` or `contextOptions` for Playwright. Since the provider package brings its own type definitions, the locators, user events, and matchers in your tests are correctly typed without any extra TypeScript configuration.

Finally, I can remove the `preview` provider since I won't be needing it anymore:

```sh nonumber
npm uninstall @vitest/browser-preview
```
